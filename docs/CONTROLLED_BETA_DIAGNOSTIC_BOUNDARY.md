# Rejected-model diagnostic boundary

`projectPublishedPlayer` now reads valuation conclusions only from the explicitly selected
model tier. A selected ACCESSIBLE result never borrows FULL composites, volatility or fallback
counts; FULL never borrows an ACCESSIBLE role, explanation, factors, position value or
provenance. Missing/malformed selected output does not become a successful INSUFFICIENT result:
the requested tier remains visible, while its unsupported numbers and claims are withheld.

An explicit INSUFFICIENT, unavailable or unrecognized-tier result publishes no composites,
confidence headline, role claim, factors, provenance claim or substituted-input headline.
Identity, evidence date, execution/readiness facts, limitations and the legitimate insufficient
reason remain available. No historical observations or stored diagnostic envelopes are deleted.

The browser adapter repeats the suppression for older exports. It rejects a contradictory
canonical value attached to an unavailable model instead of manufacturing nulls or renumbering
other players. Accepted canonical values and ranks are carried through unchanged. An explicit
canonical null suppresses headline confidence/role claims even if the legacy export retained
internal diagnostic composites; it remains unvalued.

## Compatibility default

The raw artifact projection can still read truly pre-tier engine composites by presence.
However, the browser's existing schema defaults an absent tier to INSUFFICIENT; that default
now actually withholds unsupported values/claims rather than merely printing an insufficient
badge beside them. No producing model is inferred from attractive numbers. Genuine legacy
boards with declared FULL/ACCESSIBLE retain their established composite/rank compatibility
path. This is explicitly tested. The inspected current retained capture declares model tiers.

These are projection/validation changes, not new model formulas, evidence sufficiency rules,
or authorization to publish the experimental evaluator.
